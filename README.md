# Hotel Data Cleaning & Power BI Analysis

## Project Overview

This project involved cleaning, transforming, and analyzing a hotel dataset and presenting the findings through an interactive Power BI dashboard.

The project was completed as a  semester final  project under the **HCLTech Mentorship Program**, where the focus was on applying practical data analytics techniques to a real-world style dataset.

## Objectives

- Clean and prepare the hotel dataset for analysis
- Identify and handle data quality issues
- Transform the data into a suitable format for analysis
- Explore patterns and trends within the hotel data
- Create an interactive Power BI dashboard to present the analysis

## Tools & Technologies

- **Microsoft Excel** – Data organization and initial data preparation
- **Power Query** – Data cleaning and transformation
- **Microsoft Power BI** – Data analysis and visualization

## Project Workflow

**Raw Dataset → Data Cleaning → Data Transformation → Analysis → Power BI Dashboard**

### Data Cleaning

The dataset was reviewed and cleaned to improve its quality and consistency before analysis. The original and cleaned data are included in the Excel workbook.

### Power BI Analysis

The cleaned data was used to create an interactive Power BI dashboard for exploring the hotel dataset and presenting relevant findings through visualizations.
